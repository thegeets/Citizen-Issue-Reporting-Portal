# Citizen Issue Reporting Portal

A full-stack web application for reporting, tracking, and managing citizen issues online.

## Tech Stack

* React.js
* Node.js
* Express.js
* MongoDB
* JWT

## Features

* Citizen registration and login
* Report civic issues
* Upload issue images
* Track issue status
* Admin dashboard
* Manage and update reports
* Search and filter issues
